# إطلاقات سوديك — لاندينج بيج

Next.js 15 · Tailwind 4 · **5 صفحات static** · هَب + صفحة لكل مشروع

```
/                → الهَب (كل الإطلاقات + جدول أسعار سوديك إيست)
/sodic-east      → المرحلة الجديدة — جدول الأسعار الكامل
/eastvale        → نظام السداد الجديد
/v-residence     → المبنى الجديد — استلام فوري
/karmell         → فلات فيلا — طرح محدود
```

---

## 1. الإعدادات — ملف واحد

**`app/lib/site.ts`** فيه كل حاجة: الدومين، الرقم، مفتاح Web3Forms، اسم الشركة، العنوان، ومواعيد العمل.
كمان فيه `KARMELL_RELEASE` لموعد طرح كارميل — **حدّثه أو سيبه `""` عشان الجملة تختفي** بدل ما تفضل «الإثنين القادم» للأبد.

**`app/layout.tsx`** — أول 6 سطور: `ADS_ID` والتحويلات التلاتة.

## 2. الأسعار

كلها في مصفوفة `PROJECTS` في `app/lib/site.ts`. الجداول والـFAQ والـmeta والهيرو كلهم بيقروا من نفس المكان.

**سوديك إيست — المرحلة الجديدة (من صورة البرايس ليست):**

| النوع | المساحة | السعر يبدأ من |
|---|---|---|
| 1B | 76 م² | 6,700,000 |
| 2B | 123 م² | 10,900,000 |
| 2B+N | 127 م² | 11,200,000 |
| 3B | 149 م² | 13,200,000 |
| 3B+N | 160 م² | 14,100,000 |
| 3B Duplex | 200 م² | 17,700,000 |
| 4B+N | 199 م² | 17,500,000 |

مقدم 1.5% · تقسيط 10 سنوات · Flexi Finishing · EOI 50,000 ج

**كارميل:** فلات فيلا 230 م² BUA · من 48,500,000 ج · 5% مقدم · 10 سنوات
**إيست فيل:** 5% مقدم · 10 سنوات (الأسعار لسه فاضية)
**في ريزيدنس:** غرفتين و3 غرف · استلام فوري · كامل التشطيب (الأسعار لسه فاضية)

لإضافة سعر لوحدة، غيّر `price: ""` في `units`. لو فاضي بيظهر «تواصل لآخر سعر».

## 3. الصور

| الملف | المكان |
|---|---|
| `hero.webp` | هيرو الصفحة الرئيسية |
| `sodic-east.webp` / `-hero` / `-1,2,3` | كارت + هيرو + معرض سوديك إيست |
| `eastvale.webp` / `-hero` / `-1,2,3` | إيست فيل |
| `v-residence.webp` / `-hero` / `-1,2,3` | في ريزيدنس |
| `karmell.webp` / `-hero` / `-1,2,3` | كارميل |

أي صورة ناقصة بتختفي لوحدها من غير ما التصميم يتكسر. متحطش لوجو سوديك في الهيدر أو الفوتر.

## 4. التشغيل

```bash
npm install && npm run build && npm run dev
```

## محتاج تأكيد منك

- **موقع كارميل** — كتبتها «غرب القاهرة» بشكل عام. لو عندك الموقع التفصيلي غيّر `loc` و `city`.
- **موقع إيست فيل** — نفس الحكاية، كتبتها «شرق القاهرة».
- **جدية الحجز (EOI)** — مكتوب إن شروط الاسترداد بتتحدد من المطوّر. لو مسترد فعلاً قولّي وأضيفها، دي نقطة بتقفل ديلز.

## الامتثال

- «وكيل مبيعات معتمد لدى سوديك» مكتوبة صراحة (انت وكيل فعلاً) + «لسنا الشركة المطوّرة» في الفوتر والمودال والـFAQ
- إشعار علامات تجارية · `PRICE_NOTE` متكرر في كل صفحة
- Honeypot في كل الفورمز · Cookie consent بـ Google Consent Mode v2
- 3 تحويلات: فورم / واتساب / اتصال
- زرار واتساب **جنب كل صف في جدول الأسعار** برسالة فيها نوع الوحدة ومساحتها وسعرها
- أزرار عائمة جانبية على الديسكتوب + شريط سفلي على الموبايل
- كل صفحة مشروع ليها canonical و meta خاصين — تقدر توجّه كل أد جروب على صفحته
