# سوديك إيست — المرحلة الجديدة | لاندينج بيج

Next.js 15 · Tailwind 4 · صفحة واحدة static · بهيكل modon-raselhekma.org بألوان سوديك

---

## الهيكل

```
شريط إعلان → هيدر لاصق → هيرو (4 أرقام + إفصاح)
→ فورم استلام الأسعار
→ الوحدات والأسعار (7 كروت · فلاتر · ترتيب · CTA لكل وحدة)
→ حاسبة التقسيط
→ عن المرحلة
→ المشروع على الطبيعة (الصورة الحقيقية)
→ ليه المرحلة دي (4 نقاط)
→ الخدمات → الموقع → الصور → FAQ
→ عروض سوديك الأخرى (واتساب + اتصال لكل واحد)
→ فورم نهائي → فوتر
```

## 1. الإعدادات

**`app/lib/site.ts`** — الرقم، مفتاح Web3Forms، اسم الشركة، الإيميل، وكل بيانات الوحدات.
**`app/layout.tsx`** — أول 6 سطور: `ADS_ID` والتحويلات التلاتة.

## 2. الوحدات والأسعار

مصفوفة `UNITS`. الأسعار أرقام مش نصوص عشان **الحاسبة** والترتيب والفلاتر يشتغلوا عليها.

| النوع | الكود | المساحة | السعر |
|---|---|---|---|
| شقة غرفة | 1B | 76 م² | 6,700,000 |
| شقة غرفتين | 2B | 123 م² | 10,900,000 |
| غرفتين + خادمة | 2B+N | 127 م² | 11,200,000 |
| شقة 3 غرف | 3B | 149 م² | 13,200,000 |
| 3 غرف + خادمة | 3B+N | 160 م² | 14,100,000 |
| 4 غرف + خادمة | 4B+N | 199 م² | 17,500,000 |
| دوبلكس 3 غرف | 3B Duplex | 200 م² | 17,700,000 |

مقدم `1.5%` · تقسيط `10 سنوات` · `Flexi Finishing` · EOI `50,000 ج`
(كلهم ثوابت في أول `site.ts` — `DOWN` و`YEARS` و`EOI` و`FINISH`)

## 3. الحاسبة

بتقسّم المتبقي بعد المقدم على **40 قسط ربع سنوي** أو **120 شهري** (10 سنوات) بالتساوي وبدون فوائد.
لو المطوّر بيحسبها بشكل مختلف، عدّل `n` في دالة `calc` جوه `Calculator`.
مكتوب تحتها وفي المودال إن الحساب استرشادي والمعتمد هو جدول المطوّر.

## 4. الصور

كلها متحطّة ومتقصّة ومتحوّلة webp (2.1MB إجمالي).

| الملف | المصدر | المكان |
|---|---|---|
| `hero.webp` | اللقطة الجوية للمنطقة التجارية وقت الغروب | الهيرو |
| `district.webp` | نفس الصورة بقص 4:3 | قسم «عن المرحلة» |
| `onsite.webp` | **الصورة الحقيقية من الموقع** | قسم «على الطبيعة» |
| `apartments-1/2.webp` | رندرات مباني الشقق | كروت الوحدات |
| `kitchen` · `living` · `villa` | رندرات داخلية وفيلا | كروت الوحدات والعروض |
| `aerial.webp` | اللقطة الجوية للفيلات | الموقع + إيست فيل |
| `g1` … `g6` | كلهم بقص 16:9 | المعرض |

**الصورة الحقيقية من الموقع هي أقوى أصل عندك في الصفحة دي** — أي حد بيبيع في التجمع عنده رندرات، بس صورة مباني منفّذة ولاندسكيب مزروع دي اللي بتفرق. حطيتلها قسم كامل لوحدها.

## 5. العروض الأخرى

قسم `#offers` فيه إيست فيل وفي ريزيدنس وكارميل — كل واحد بكارت وزرار واتساب (برسالة باسم المشروع) وزرار اتصال. مفيش صفحات منفصلة ليهم.

## 6. التشغيل

```bash
npm install && npm run build && npm run dev
```

## محتاج تأكيد

- **الموقع** — كتبت «شرق القاهرة» وذكرت الدائري الأوسطي ومحور بن زايد والعاصمة. لو عندك المسافات بالدقايق بالظبط ابعتها وأنا أحطها بدل «قريب».
- **الخدمات** — كتبتها عامة (تجاري، كلوب هاوس، مدارس، أمن). لو عندك ليست الخدمات الرسمية للمرحلة ابعتها.
- **جدية الحجز مستردة ولا لأ؟** — مكتوب إن شروطها بتتحدد من المطوّر.
